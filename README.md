# 跨境电商平台（Olist）GMV 拆解与增长质量诊断

对巴西电商平台 **Olist** 做一次经营复盘：GMV 两年涨了 9.4 倍，但这轮增长到底健不健康？

**结论：不健康。增长靠拉新和低价冲量，单客价值在稀释。**

| 指标 | 数值 |
|---|---|
| 有效 GMV（商品口径） | **13,494,400.74 R$** |
| 有效订单 | **98,199** |
| 客单价 | **137.42**（商品口径）/ 160.24（含运费） |
| 连带率 | **1.14** |
| 复购率 | **3.04%** |
| 品类 CR5 | **39.77%** |

数据区间 2016-09 ~ 2018-08。原始 9 张 CSV、99,441 张订单、112,101 行明细。

> 姊妹项目：[china-trade-analysis](https://github.com/lisking805/china-trade-analysis)
> （中国－共建国家贸易 2020–2024 结构分析与 Power BI 八页看板）

## 一、月度趋势：先把残月剔掉，才谈得上趋势

![月度GMV趋势](01_月度GMV趋势.png)

**第一步不是画趋势，是查哪些月份不完整。**

| 残月 | 订单数 |
|---|---|
| 2016-09 | 2 单 |
| 2016-12 | 1 单 |
| 2018-09 | 1 单 |

这三个月不是"业务惨淡"，是数据没采全。留着它们画趋势线，末端会掉出一个假悬崖。

→ 剔除后，有效分析区间锁定为 **2016-10 ~ 2018-08**。

峰值出现在 **2017-11**：全部订单 **7,544** 单，其中有效 **7,421** 单。
剔除的 123 单是 `unavailable` 84、`canceled` 37、`created` 2 ——
**未支付和取消的订单不能算进 GMV**，这是本项目第一条口径。

黑五当天（2017-11-24）单日 **1,176** 单，是唯一一个有真实促销意义的尖峰。

## 二、量涨价跌：三个数串起整个结论

![量涨价跌](02_量涨价跌.png)

**单量涨 9.4 倍 × 客单价跌 13.4% × 复购率仅 3.04%**

| 时间 | 客单价（AOV） |
|---|---|
| 2017-01 | 152.60 |
| 2017-11 | 135.27 |
| 2017-12 | 132.11 |

同一时期单量涨了 9.4 倍，客单价跌了 **13.4%**。

→ **量在爆，价在跌，人不回头。** 这是典型的**拉新驱动**，不是复购驱动。
获客成本一旦上升，这轮增长会立刻失速。

## 三、品类：典型长尾，没有绝对主力

![品类TOP10](03_品类TOP10.png)

| 品类 | GMV（R$） | 均价 / 单量 |
|---|---|---|
| health_beauty | 1,255,695.13（9.3%） | 均价 130.34 |
| watches_gifts | 1,191,185.21 | **均价 200.70** |
| bed_bath_table | 1,035,964.06 | **单量 9,399**（最高），均价仅 93.36 |
| sports_leisure | 979,740.92 | — |
| computers_accessories | 904,322.02 | — |

**CR5 = 39.77%**，前五品类连四成都不到 —— 典型长尾结构。

→ 所以**不能建议"砍长尾聚焦爆款"**，把长尾砍掉等于砍掉六成营收。

真正的抓手是 `watches_gifts`：单价是 `bed_bath_table` 的 **2.15 倍**，单量却只有它的 **60%**。
**要拉高客单价，这是首选品类** —— 不是把流量切过去，而是把它推给已经在买家居品类的人。

## 四、获客渠道：招来的卖家一半是僵尸

![渠道四象限](04_渠道四象限.png)

漏斗：**8,000 线索 → 842 签约（10.53%）→ 379 出过单**

- **463 家（54.99%）从没卖出过一单**
- 这批渠道卖家合计贡献 GMV **674,005.39 R$**，只占全平台 **4.99%**

→ 典型的**重签约、轻激活**。招来的卖家一半是僵尸，营销对 GMV 的实际贡献只有 5%。

分渠道签约转化率：

| 渠道 | 转化率 | 线索数 |
|---|---|---|
| unknown | 16.29% | 1,099 |
| paid_search | **12.30%** | 1,586 |
| organic_search | 11.80% | 2,296 |
| direct_traffic | 11.22% | 499 |
| referral | 8.45% | 284 |
| social | 5.56% | 1,350 |
| display | 5.08% | 118 |
| other_publicities | 4.62% | 65 |
| email | 3.04% | 493 |
| other | 2.67% | 150 |

> ⚠️ 有 **60 条线索的 origin 字段为空**。Python 的 `groupby` 默认把 NaN 丢弃，
> 只看得到 10 行；MySQL 会老老实实显示 11 行。**以 SQL 结果为准。**

渠道转化周期（平均天数）：

```
direct_traffic 31.1 < referral 32.5 < other_publicities 39.3 < unknown 41.3
< organic_search 50.0 < email 52.2 < paid_search 56.6 < social 61.0
```

**social 双差**（转化率 5.56% + 周期 61 天，最慢）、**email 双差**（3.04% + 52.2 天）。
display（6 个签约）与 other（4 个）样本太小，不据此下结论。

## 五、物流：推翻了一个假设

![物流差评率](05_物流差评率.png)

看到复购率只有 3.04%，第一反应是**物流太差把人赶跑了**。数据说不是：

| 送达情况 | 订单数 | 平均评分 | 组内差评率 |
|---|---|---|---|
| 提前送达 | 88,168（92%） | 4.29 | 9.22% |
| 准时送达 | 1,280（1.3%） | 4.03 | 12.50% |
| 延迟 1–3 天 | 1,852 | 3.29 | 32.13% |
| 延迟 4–7 天 | 1,748 | 2.11 | 67.56% |
| 延迟 7 天以上 | 2,782（2.9%） | 1.70 | **79.30%** |

（基数 95,830 单）

- **92% 订单提前送达** —— 平台承诺时间给得极宽松，准时送达反而只占 1.3%
- 延迟 7 天以上只占 2.9%，但**这批订单里 79.3% 给了差评** —— 小概率、高杀伤
- 延迟订单贡献约 32% 的差评，却只占 6.7% 的订单量

> ⚠️ **79.3% 是「组内差评率」，不是「贡献了 79.3% 的差评」。**
> 那批订单只占全平台差评的约 23%。这两个数不能混着说。

→ 这条假设**被数据证伪了**：绝大多数用户体验良好，物流解释不了 3.04% 的低复购。
真因更可能是**品类本身低频**（家具家居买了用好几年）+ 获客质量。

## 六、复购：3.04%，低到不能再低

![复购分布](06_复购分布.png)

94,986 个 `customer_unique_id` 中，只有 **2,887 人**下过 2 单及以上 → **复购率 3.04%**。

> 连带率 1.14 也是佐证：一张订单平均只买 1.14 件，**没有连带，也就不可能有复购**。

## 七、线索价值：为了算清这条，才做 ROI

![线索价值](07_线索价值.png)

**反过来问：一个线索最多值多少钱，投这个渠道才不亏？**

假设平台佣金率 **15%**（这是本项目唯一的外部假设，改动它结论会整体平移）：

```
渠道卖家 GMV 674,005.39 × 15% = 平台收入 101,100.81 R$
```

## 八、A/B 实验：先算要多少样本，再谈要不要做

![AB样本量](08_AB样本量.png)

反向 MDE —— 不做"要测 1% 提升需要多少人"，而是问**「21 天只能测到多大的提升」**：

| 口径 | 21 天可检测的最小提升 |
|---|---|
| 原始数据（σ = 209.31） | **15.0%** |
| 截尾 P99 后（σ = 155.34） | 样本省 40% |
| 再叠加品类分层 | **10.9%** |

→ **客单价提升低于 10.9% 的方案，21 天内根本测不出来**，别浪费时间做实验。

**护栏指标不能用差评率**：基线 12.80%，提升 3pp 需要 28 天，而且评价本身滞后。
改用**延迟率**——数据产出快，灵敏度高。

**CUPED 在这里失效**：CUPED 靠历史行为做协变量降方差，复购率只有 3.04%，
绝大多数用户只有一条记录，没有"历史"可用。

### 13.2 复购那一格，把 3.04% 算给你看

这是全看板信息密度最高的一格，也是被问得最多的一格：

| 下单次数 | 人数 | 占比 |
|---|---|---|
| 1 单 | 92,099 | 96.96% |
| 2 单 | 2,651 | 2.79% |
| 3 单 | 188 | 0.20% |
| 4 单 | 48 | 0.05% |
| **合计** | **94,986** | **100%** |

复购客户 = 2,651 + 188 + 48 = **2,887 人**，2,887 ÷ 94,986 = **3.04%**。
看板里显示的 96.96% 是"只买过一次"的比例，两者是互补关系，不是矛盾。
